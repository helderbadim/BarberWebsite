# Barber Website 💈

Welcome to the Barber Website project! This is my first website built exclusively with HTML and CSS.
## 🚀 Live Demo

Check out the live version of the website:
https://helderbadim.github.io/BarberWebsite/

## 📌 Features

- Home Page: A welcoming landing page with a hero section.
- Services Section: Detailed descriptions of the services offered.
- Contact Section: Easy-to-use contact form and location details.
- Modern Aesthetic: Clean and professional design with engaging visuals.

## 🛠️ Technologies Used

- HTML5: For semantic and structured content.
- CSS3: For styling and responsive design.
- GitHub Pages: For hosting the live demo.

## 📂 Project Structure

BarberWebsite/
├── index.html         # Main HTML file
├── styles/            # Folder containing CSS styles
│   ├── style.css      # Main stylesheet

│   ├── favicon.ico    # Favicon for the website (if included)
├── README.md          # Project documentation (this file)
└── LICENSE            # License for the project (if included)

## 🎯 Purpose

This project was created as part of my front-end development learning journey and is my first attempt at building a complete, responsive website using only HTML and CSS. It demonstrates my ability to structure code, create clean designs, and ensure compatibility across devices.
